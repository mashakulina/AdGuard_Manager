# Изменения в версии 1.1

## Установка

- Добавлен установщик `AdGuard_VPN_Manager_Install.desktop`: достаточно открыть
  ярлык, чтобы скачать, распаковать и установить менеджер.
- При чистой установке CLI выбирается последняя стабильная версия из официального
  источника AdGuard. Убрана привязка к старой версии 1.5.10.
- Пакет выбирается с учётом архитектуры устройства и актуального адреса релиза.
  Ошибка получения версии больше не приводит к молчаливой установке старого CLI.
- При ошибке скачивания или проверки архива установщик сохраняет существующую
  программу. Добавлены проверки Python и Tkinter и понятные сообщения об ошибках.

## Интерфейс и скорость работы

- Обновлена компоновка окон для Steam Deck, небольших экранов и разных масштабов.
  Длинные подписи переносятся, содержимое можно прокручивать, кнопки остаются доступны.
- Добавлена обработка сенсорных касаний в Wayland для установки, проверки аккаунта,
  авторизации и главного окна с дочерними диалогами. В X11 используется штатный ввод.
- Запросы к CLI выполняются в фоне. Окна, меню и личный кабинет остаются
  отзывчивыми во время загрузки данных.
- Сокращены повторные запросы лицензии и статуса. Временные ошибки получения
  лицензии не стирают уже полученные данные аккаунта.
- Исправлено отображение многословных названий локаций, включая New York.

## Авторизация

- Если вход не выполнен, сначала открывается окно авторизации, затем менеджер.
- Исправлено чтение ссылки из разных потоков CLI, в том числе без перевода строки.
  Добавлены повторное получение ссылки и копирование полного адреса.
- Если браузер по умолчанию отсутствует или не запускается, менеджер ищет
  установленный браузер, включая поддерживаемые Flatpak-приложения.
- При ошибке доступно окно «Подробности» с кодом завершения, длительностью
  и очищенным выводом CLI. Ссылки входа и секретные данные скрываются.
- Исправлены редкое падение при переходе к менеджеру после входа, обработка
  запоздалых ответов предыдущей попытки и очистка процессов при отмене.

## Обновления

- Исправлено распознавание доступного обновления: инструкция с упоминанием
  «latest version» больше не считается подтверждением актуальной версии.
- Ответ `check-update` с кодом 17 и подтверждением актуальности корректно
  обрабатывается в каналах Release и Beta.
- Журнал обновления показывает команду, код завершения, длительность,
  stdout/stderr, таймаут и версии до и после. Его можно прокручивать и копировать.
- Успех обновления подтверждается изменением установленной версии. Если CLI
  предложил одну версию, а установилась другая, это отдельно отмечается в журнале.
- Добавлены пояснения к ошибкам загрузки, DNS, TLS, HTTP и прав доступа.
  Сетевые ошибки не выдаются за отсутствие обновлений.
